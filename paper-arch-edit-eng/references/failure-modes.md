# 失败模式（命中即回退）

1. 机制未映射到具体文件/函数 → 回阶段 0
2. 接口契约靠猜未实测 → 回阶段 1
3. spec 含多个机制单元、无法单独回滚 → 回阶段 2
4. 改动无测试或只有 smoke test → 回阶段 3
5. 等价性在混合精度下破裂 → 阻塞合并，回阶段 3
6. 随机容量基线追平增益 → flag 默认关闭，标 experimental
7. 配对种子下 |Δ| < 2SE 却写"提升" → 改措辞或补种子
8. flag 默认开启 → 回阶段 2
9. 交付包缺门结果或复现脚本 → delivery_audit 失败
10. 讨论只谈机制优雅、不落三问（落点/测试/门）→ 标记 pending
