# 验证门（合并前门）

## 门 1：随机容量匹配
- 构造：随机特征/随机门控/随机掩码补足同等参数与 FLOPs
- 判据：随机基线达到设计增益的 ≥90% → 设计未验证
- 处置：flag 默认关闭，PR 注明 "experimental"

## 门 2：随机标签对照
- 构造：随机标签训练同配置
- 判据：同向增益出现 → 机制解释未验证
- 处置：同上

## 门 3：配对种子
- 构造：≥5 种子，同划分，配对比较
- 判据：|Δ| < 2×配对SE → 不得声称提升
- 处置：README/PR 改用"未见显著差异"

## 门 4：回归基准
- 构造：baseline 与改造在同一套配置下配对跑
- 判据：跑通且统计达标
- 处置：未跑通阻塞合并

## 门 5：等价性（重参数化/掩码）
- 构造：固定输入，比较转换前后输出
- 判据：float32 与混合精度下 max diff ≤ 阈值（按 dtype 设）
- 处置：强制阻塞合并

## 记录格式
每道门输出 JSON：{gate, passed, metric, threshold, evidence_path}
